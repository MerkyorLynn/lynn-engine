## How the Script Works

`scripts/summarize_qwen35_9b_release_matrix.py` performs:

1. **Auto-discovery** — Globs for report files by pattern and selects the latest by mtime.
2. **Schema-tolerant parsing** — Handles multiple report formats (combined quality summary,
   individual MMLU/GPQA summaries, Q4_K_M baseline with nested TPS/concurrent/long-context).
3. **Status derivation** — Computes variant status (DONE/PARTIAL/PENDING/BLOCKED) from
   the presence and values of quality + performance data.
4. **Diff detection** — Compares against any existing `*release_matrix*.json` to report changes.
5. **Dual output** — Emits structured JSON (`lynn-qwen35-9b-release-matrix-v1` schema) and
   a human-readable Markdown document.

## Regenerating

```bash
python3 scripts/summarize_qwen35_9b_release_matrix.py \
    --report-dir reports/qwen35_9b \
    --output-json reports/qwen35_9b/qwen35_9b_release_matrix.json \
    --output-md reports/qwen35_9b/qwen35_9b_release_matrix.md
```
