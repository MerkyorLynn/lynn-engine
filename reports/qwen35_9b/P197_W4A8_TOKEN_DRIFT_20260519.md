## Background

P190/P197 reported **CLOSED (RED)** for the true FP4xFP8 resident decode path
on Qwen3.5-9B. Greedy-decoded tokens diverge from the W4A16 reference within
the first 8 steps on multiple prompts.

## Architecture of True FP8 Path

```
hidden (BF16, [1, 4096])
  → quantize_to_fp8_e4m3_per16() → [4096] uint8 + [256] fp32_scale
  → gate_proj: FP4(weight) × FP8(act) → [12288] FP32
  → up_proj:   FP4(weight) × FP8(act) → [12288] FP32
  → silu(gate) * up                    → [12288] FP32
  → quantize_to_fp8_e4m3_per16()       → [12288] uint8 + [768] fp32_scale
  → down_proj: FP4(weight) × FP8(act) → [4096] FP32
  → cast to BF16, add to residual
```

Each layer repeats this 36 times (Qwen3.5-9B has 36 layers).

## Potential Drift Sources

| ID | Source | Mechanism | Isolation Knob |
|----|--------|-----------|----------------|
| A | MMA fragment layout | Raw MMA output wrong (P191 cosine -0.015) | `KERNEL=mma` vs `KERNEL=scalar` |
| B | gate/up FP8 quant | Per-16 E4M3 truncates hidden-state outliers | `SCOPE=gateup` |
| C | down_proj re-quant | silu*up intermediate has higher dynamic range → E4M3 clips | `SCOPE=down` |
| D | Per-16 scale resolution | 16-element groups may miss sharp peaks | Compare per-row vs per-16 |
| E | Residual accumulation | 36 layers × small error per layer → drift | Layer-selective bypass |

## Isolation Probe Design (P197b)

P197b runs these modes against W4A16 reference:

1. **scalar_full**: All 3 projections via scalar reference (P191 GREEN).
   - If NO_DRIFT → root cause is MMA only → fix fragment layout.
   - If DRIFT → quantization error is real, independent of MMA.

2. **scalar_gateup_only**: Gate+up via FP8 scalar, down stays BF16.
   - If NO_DRIFT → down_proj re-quant is the sole problem.

3. **scalar_down_only**: Gate+up stay BF16, only down via FP8 scalar.
   - If NO_DRIFT → gate/up quant is the sole problem.

4. **mma_full**: Production MMA path.
   - Baseline for comparison with scalar_full.

## Expected Outcomes

### If scalar_full = NO_DRIFT:
**Root cause: MMA fragment layout only.**
- The FP8 quantization math is correct.
- Fix = resolve P191 fragment register packing.
- Once fragments are correct, W4A8 should pass STRICT.
- This is the best-case scenario: engineering fix, not fundamental.

### If scalar_full = RED:
**Root cause: FP8 quantization itself.**
- Proceed to split gateup vs down to identify major contributor.
- Likely fix candidates:
  - Keep down_proj in BF16 (hybrid: FP8 gate/up + BF16 down)
  - Per-row activation scale instead of per-16
  - Layer-selective: only apply FP8 to middle layers (skip first/last few)

### If scalar_full = AMBER:
**Root cause: FP8 quantization with manageable drift.**
- Document which tokens drift and whether they're semantic equivalents.
- If top-1 margins are < 0.01, drift is noise in low-confidence positions.
- May be acceptable for decode speed if clearly documented.
