## Interpretation

The all-40 synthetic/runtime preflight remains RED for direct full-active W4A8
promotion.  This matches the broader P104/P105 conclusion: gate/up W4A8 is the
safer first bridge, while full active-MoE W4A8 still needs stronger Recovery or
QAT-lite before it becomes a production default.

The important nuance is that `structured_v10_top6` and BF16 final are identical
on this stress gate.  So this result should **not** be read as "v10 folded made
the model worse."  It shows that the tested W4A8 runtime quantization path is
still the bottleneck.  Candidate ranking should continue to rely on generation
gates plus R6000 runtime smoke:

```text
structured_v10_top6: 8/12 exact, min prefix 13, mean prefix 33.33
structured_v9_top5:  8/12 exact, min prefix 7,  mean prefix 34.25
```

## Decision

Keep `structured_v10_top6` as the Lynn 27B A3B W4A8 NVFP4 v2 handoff package,
but do not promote full-active W4A8 by default.  Continue:

1. transfer v2 to R6000 and Spark;
2. run SHA/integrity gates after transfer;
3. run gate/up-first runtime experiments on R6000;
4. keep full-active W4A8 behind explicit experimental gates until generation
   and tool/JSON strictness improve.
