## Divergence Contract

Generation divergence means the W4A8 candidate stops reproducing the BF16
reference token sequence at some position. It is a strict reproduction loss,
not automatically a user-visible quality loss.

High-risk divergence:

- tool-call JSON changes, invalid schema, or field drift;
- code blocks or exact-format tasks changing early;
- `<think>` loops, punctuation loops, or degenerate repetition;
- refusal / safety behavior changing unexpectedly.

Lower-risk divergence:

- natural-language explanations that paraphrase after a long shared prefix;
- late stylistic changes with the same factual answer.

For promotion, exact-match is still the hard gate. For research ranking,
prefix length and failure type should be tracked so promising recovery
candidates are not discarded too early.
